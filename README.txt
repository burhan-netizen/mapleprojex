MAPLE PROJEX WEBSITE
====================

Preview:
- Open index.html in a modern browser.
- Keep the assets folder alongside index.html.

Included:
- Responsive single-page website
- Maple Projex supplied logo and project photography
- Three supplied MP4 clips
- GSAP + ScrollTrigger reveal and parallax motion
- Lenis smooth scrolling (CDN)
- SEO title, description, keywords and JSON-LD GeneralContractor schema
- Open Graph and Twitter social sharing metadata and generated 1200x630 image
- Contact form that opens the visitor's email client addressed to greg@mapleprojex.com

Before launch:
1. Confirm service list and geographic coverage with Maple Projex.
2. Confirm final website domain, then add canonical URL, og:url and sitemap.xml.
3. Connect the enquiry form to a real form handler/CRM if you want submissions without the visitor's email app.
4. Confirm all project photographs are approved for public website use.
5. Add verified business address, licence details and testimonials only if supplied by the business.

Fonts and animation libraries load from public CDNs; an internet connection is needed for those enhancements.
